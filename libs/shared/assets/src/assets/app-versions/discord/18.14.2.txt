**Firestone 18.14.2 — Release notes**

**Battlegrounds**
- ✨ Update simulator for 36.2. You can now check the simulator's accuracy at https://www.firestoneapp.com/monitoring/simulator (updated daily)
- ✨ Tooltip when mousing over the Dark Gifts button
    - It shows you all the minions you can get, and which Dark Gifts any given minion can get
    - Can be turned off in Settings > Battlegrounds > Overlay
- ✨ Faster time to first battle simulation in the overlay
- ✨ MMR is visible without mousing over opponent icons
- ✨ Horizontal scrollbar on the compositions tab
- ✨ Aureate Laureate is excluded from auto-highlights
- ✨ Tavern buff counter includes For the Horde!
- ✨ Added missing achievements for recent heroes
- ✨ Toggle on the Powers tab to switch between expanded and compact views
- ✨ Choose One and Discover are now listed in the main mechanics entries of the cards list
- 🐞 Fixed sim issues and improved simulator performance
- 🐞 Fix an issue where counters would not appear in Battlegrounds anymore
- 🐞 Fix an issue where battle odds would not stay visible in the tavern
- 🐞 Fix an issue where some heroes (e.g. Teron, Onyxia) would not show stats in the hero selection overlay
